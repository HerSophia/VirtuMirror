### 1.2 路由与导航

项目使用 Vue Router 4 的 Memory History 模式，不会修改浏览器 URL，适合嵌入式应用。

**导航方式对比**:

| 旧方式 (uiStore) | 新方式 (Vue Router) |
| ------------------ | --------------------- |
| `uiStore.navigateTo('chat')` | `router.push('/chat')` |
| `uiStore.goBack()` | `router.back()` |
| `uiStore.activeContactId` | `route.params.contactId` |

### 2.4 ViewsContainer.vue

**文件**: `src/components/phone/ViewsContainer.vue`

路由视图容器，使用 Vue Router 的 `<router-view>` 管理视图切换，集成了多项性能优化。

**核心模板**:
```vue
<router-view v-slot="{ Component, route: currentRoute }">
  <!-- 并行动画（移除 mode="out-in"） -->
  <Transition :name="transitionName">
    <!-- Suspense 处理异步组件加载 -->
    <Suspense>
      <!-- KeepAlive 缓存常用组件 -->
      <KeepAlive :include="cachedComponents">
        <component
          :is="Component"
          :key="currentRoute.path"
          class="view"
        />
      </KeepAlive>
      
      <!-- 加载中的骨架屏 -->
      <template #fallback>
        <SkeletonGroup preset="list-item" :count="5" />
      </template>
    </Suspense>
  </Transition>
</router-view>
```

**性能优化策略**:

| 优化项 | 实现方式 | 效果 |
| -------- | ---------- | ------ |
| 并行动画 | 移除 `mode="out-in"` | 新旧页面同时执行过渡，更流畅 |
| 组件缓存 | `<KeepAlive>` | 避免常用页面重复渲染 |
| 异步加载 | `<Suspense>` | 优雅处理懒加载组件 |
| 骨架屏 | `#fallback` 插槽 | 加载时显示占位，避免空白 |
| 组件预加载 | `preloadComponents()` | 空闲时预加载可能访问的组件 |

**缓存组件列表**（来自 `router/index.ts`）:
```typescript
export const cachedComponents: string[] = [
  'HomeScreen',
  'ChatApp',
  'SettingsApp',
  'EmailApp',
  'BrowserApp',
  'LiveCenterApp',
]
```

**过渡动画**:
| 动画名称 | 效果 | 应用场景 |
| --------- | ------ | ---------- |
| `slide` | 新页面从右滑入，旧页面向左淡出 | App 内部前进导航 |
| `slide-back` | 新页面从左滑入，旧页面向右滑出 | App 内部后退导航 |
| `zoom-in` | 从图标位置放大展开 | 从桌面打开 App |
| `zoom-out` | 缩小到图标位置 | 从 App 返回桌面 |
| `fade` | 淡入淡出 | 模态切换 |

**iOS 风格并行动画 CSS**:
```css
/* 前进：新页面叠加在旧页面上方 */
.slide-enter-active {
  z-index: 2;
  transition: all 0.3s cubic-bezier(0.25, 0.46, 0.45, 0.94);
}
.slide-leave-active {
  position: absolute;
  z-index: 1;
}
.slide-enter-from { transform: translateX(100%); }
.slide-leave-to { transform: translateX(-30%); opacity: 0.6; }

/* 后退：旧页面叠加在新页面上方 */
.slide-back-enter-active { z-index: 1; }
.slide-back-leave-active {
  position: absolute;
  z-index: 2;
}
.slide-back-enter-from { transform: translateX(-30%); opacity: 0.6; }
.slide-back-leave-to { transform: translateX(100%); }
```

**手势系统**:

ViewsContainer 实现了完整的手势导航系统，支持多种手势操作：

| 手势 | 触发区域 | 触发条件 | 动作 | 视觉反馈 |
| ------ | ---------- | ---------- | ------ | ---------- |
| 左侧向右滑动 | 屏幕左侧 1/4 | 距离 > 80px 或速度 > 0.5px/ms | 返回上一页 | 左侧箭头指示器 |
| 右侧向左滑动 | 屏幕右侧 1/4 | 距离 > 80px 或速度 > 0.5px/ms | 返回上一页 | 右侧箭头指示器 |
| 底部快速上滑 | 屏幕底部 60px | 速度 ≥ 0.8px/ms | 返回桌面 | 底部横条 + 文字提示 |
| 底部慢速上滑 | 屏幕底部 60px | 速度 < 0.8px/ms 且距离 > 100px | 打开多任务切换 | 底部横条 |

**手势参数配置**:
```typescript
const SWIPE_THRESHOLD = 80           // 水平滑动距离阈值
const SWIPE_HOME_THRESHOLD = 100     // 返回桌面/多任务滑动距离阈值
const HOME_SWIPE_VELOCITY = 0.8      // 快速滑动回桌面速度阈值 (px/ms)
const APP_SWITCHER_VELOCITY = 0.3    // 慢速上滑打开多任务切换速度阈值 (px/ms)
```

**底部上滑逻辑**:
```typescript
// 判断上滑速度来决定行为
if (velocity >= HOME_SWIPE_VELOCITY) {
  // 快速上滑 → 返回桌面
  router.push('/')
} else if (route.path !== '/') {
  // 慢速上滑 + 不在桌面 → 打开多任务切换
  appStateStore.showAppSwitcher()
}
```

**手势状态**:
```typescript
const isFromLeftEdge = ref(false)    // 是否从左边缘开始
const isFromRightEdge = ref(false)   // 是否从右边缘开始
const isFromBottomEdge = ref(false)  // 是否从底部边缘开始
const isSwipingBack = ref(false)     // 是否正在水平滑动返回
const isSwipingHome = ref(false)     // 是否正在向上滑动回桌面
const swipeProgress = ref(0)         // 水平滑动进度 (0-1)
const swipeHomeProgress = ref(0)     // 上滑进度 (0-1)
```

**返回条件判断**:
- 使用路由导出的 `canGoBack` 计算属性判断是否可以返回上一页
- 使用 `route.path !== '/'` 判断是否可以返回桌面

**动画配置**:
通过路由 meta 配置缓存行为：
```typescript
{
  path: '/chat',
  name: 'ChatApp',
  component: ChatApp,
  meta: { keepAlive: true }  // 启用 KeepAlive 缓存
}
```

**Zoom 动画原点**:
zoom 动画的 `transform-origin` 由 CSS 变量 `--zoom-origin-x` 和 `--zoom-origin-y` 控制：
```typescript
// 动画原点样式
const zoomOriginStyle = computed(() => {
  if (transitionType.value !== 'zoom') return {}
  return {
    '--zoom-origin-x': `${zoomOrigin.value.x}%`,
    '--zoom-origin-y': `${zoomOrigin.value.y}%`
  }
})
```

**与 appStateStore 的集成**:
ViewsContainer 监听路由变化，返回桌面时自动设置 zoom 原点：
```typescript
watch(
  () => route.path,
  (newPath, oldPath) => {
    if (transitionType.value !== 'zoom') return
    
    // 返回桌面时，使用当前 App 的图标位置
    if (newPath === '/' && oldPath && oldPath !== '/') {
      const appId = getAppIdFromRoute(oldPath)
      const iconPosition = appStateStore.getIconPosition(appId)
      if (iconPosition) {
        setZoomOrigin(iconPosition)
      }
    }
  }
)
```

### 3.3 AppSwitcher.vue

**文件**: `src/components/phone/AppSwitcher.vue`

多任务切换器组件，显示运行中的 App 卡片列表，支持切换和关闭 App。

**触发方式**:
- 从屏幕底部 60px 区域慢速向上滑动（速度 < 0.8px/ms，距离 > 100px）

**功能**:
- 显示运行中的 App 卡片（横向滚动）
- 点击卡片切换到对应 App
- 上滑/左右滑动卡片关闭该 App
- 点击空白区域返回桌面
- 一键清除所有运行中的 App
- 支持键盘导航（方向键/Enter/Escape）

**Props**: 无（通过 appStateStore 控制显示）

**核心模板**:
```vue
<Teleport to="body">
  <Transition name="app-switcher">
    <div v-if="isVisible" class="app-switcher-overlay" @click="goHome">
      <!-- 顶部区域（点击返回桌面） -->
      <div class="switcher-header" @click="goHome">
        <!-- 可扩展：显示日期时间等 -->
      </div>
      
      <!-- 卡片列表容器 -->
      <div class="cards-container" @click.self="goHome">
        <div
          v-for="app in runningAppInfos"
          :key="app.appId"
          class="app-card-wrapper"
        >
          <!-- App 图标和名称 -->
          <div class="app-info">
            <div class="app-icon" :style="{ background: app.iconBg }">
              <i :class="app.icon" />
            </div>
            <span class="app-name">{{ app.name }}</span>
          </div>
          
          <!-- App 预览卡片（可上滑关闭） -->
          <div
            class="app-card"
            @click.stop="switchToApp(app)"
            @touchstart="onCardTouchStart"
            @touchmove="onCardTouchMove"
            @touchend="onCardTouchEnd(app.appId)"
          >
            <!-- 卡片内容/截图占位 -->
          </div>
        </div>
      </div>
      
      <!-- 底部区域 -->
      <div class="switcher-footer" @click.self="goHome">
        <button class="clear-all-btn" @click.stop="clearAllApps">
          <i class="fas fa-trash" />
          <span>清除全部</span>
        </button>
      </div>
    </div>
  </Transition>
</Teleport>
```

**手势交互**:

| 手势 | 作用对象 | 效果 |
| ------ | ---------- | ------ |
| 点击 | 卡片 | 切换到该 App |
| 上滑 | 卡片 | 关闭该 App |
| 左/右滑 | 卡片 | 关闭该 App |
| 左右滑动 | 列表区域 | 浏览不同 App |
| 点击 | 空白区域 | 返回桌面 |
| 点击 | 清除按钮 | 关闭所有 App |

**方向锁定机制**:
```typescript
// 防止水平滚动和垂直关闭手势冲突
const lockedDirection = ref<'horizontal' | 'vertical' | null>(null)

function onCardTouchMove(e: TouchEvent) {
  const deltaX = Math.abs(currentX - startX)
  const deltaY = Math.abs(currentY - startY)
  
  // 移动超过 10px 后锁定方向
  if (!lockedDirection.value && (deltaX > 10 || deltaY > 10)) {
    lockedDirection.value = deltaX > deltaY ? 'horizontal' : 'vertical'
  }
  
  // 根据锁定方向执行对应操作
  if (lockedDirection.value === 'vertical') {
    // 处理卡片上滑关闭
  }
  // horizontal 方向由 CSS scroll-snap 处理
}
```

**键盘导航**:
| 按键 | 动作 |
| ------ | ------ |
| ← / → | 切换焦点到上/下一个卡片 |
| Enter | 切换到当前焦点的 App |
| Escape | 关闭切换器返回桌面 |

**样式特点**:
- 毛玻璃背景效果（backdrop-filter: blur）
- 卡片使用 scroll-snap 实现对齐
- 上滑关闭时卡片向上移动并淡出
- 入场/退场动画（从底部滑入/滑出）

**与 appStateStore 集成**:
```typescript
import { useAppStateStore } from '@/stores/appStateStore'

const appStateStore = useAppStateStore()

// 响应式数据
const isVisible = computed(() => appStateStore.isAppSwitcherVisible)
const runningAppInfos = computed(() => appStateStore.runningAppInfos)

// 操作方法
function switchToApp(app: AppInfo) {
  appStateStore.hideAppSwitcher()
  router.push(app.lastRoute)
}

function closeApp(appId: string) {
  appStateStore.closeApp(appId)
  // 如果没有运行中的 App 了，返回桌面
  if (appStateStore.runningApps.length === 0) {
    goHome()
  }
}

function clearAllApps() {
  appStateStore.clearAllRunningApps()
  goHome()
}

function goHome() {
  appStateStore.hideAppSwitcher()
  router.push('/')
}
```

**核心模板**:

```vue
<template>
  <div v-if="!deviceStore.isGestureNavigation" class="navigation-bar">

    </button>
    <button @click="goHome" class="nav-btn">
      <div class="nav-icon home-icon" />
    </button>
    <button @click="openAppSwitcher" class="nav-btn">
      <div class="nav-icon recent-icon" />
    </button>
```

**主页键动画处理**:
```typescript
function goHome() {
  if (route.path === '/') return
  
  // 获取当前 App 图标位置作为 zoom 动画终点
  const currentAppId = getAppIdFromRoute(route.path)
  const iconPosition = appStateStore.getIconPosition(currentAppId)
  
  if (iconPosition) {
    setZoomOrigin(iconPosition)
  }
  
  setTransitionType('zoom')
  router.push('/')
}
```

**样式特点**:
- 高度 48px，背景半透明 (`bg-black/80`)
- 三个按键等分宽度，使用 Flexbox 布局
- 图标使用 CSS 绘制（三角形、圆形、正方形）
- 按键点击时有缩放反馈 (`active:scale-95`)
- 返回键不可用时显示为灰色

**与 ViewsContainer 的位置关系**:
NavigationBar 位于 ViewsContainer 下方，两者同属 PhoneContainer 内部：

**Props**:
```typescript
interface Props {
  appId: AppIconId     // App 标识符
  size?: 'sm' | 'md' | 'lg' | 'xl'  // 图标大小，默认 'md'
  badge?: number       // 右上角徽章数字
  showLabel?: boolean  // 是否显示标签文字
  label?: string       // 自定义标签
}

// App 标识符类型
```

```typescript
import { useAppStateStore, getAppIdFromRoute } from '@/stores/appStateStore'

const appStateStore = useAppStateStore()

// 收集所有图标的 DOM 引用
const iconRefs = ref<Map<string, HTMLElement>>(new Map())

// 注册单个图标引用
function setIconRef(appId: string, el: HTMLElement | null) {
  if (el) {
    iconRefs.value.set(appId, el)
  }
}

// 注册所有图标位置
function registerAllIconPositions() {
  if (!containerRef.value) return
  
  iconRefs.value.forEach((element, appId) => {
    appStateStore.registerIconFromElement(appId, element, containerRef.value!)
  })
}

// 组件挂载/激活时注册
onMounted(() => nextTick(() => registerAllIconPositions()))
onActivated(() => nextTick(() => registerAllIconPositions()))
```

```typescript
const router = useRouter()

function openApp(app: AppItem, event: MouseEvent | TouchEvent) {

  if (iconPosition) {
    setZoomOrigin(iconPosition)
  }
```

```typescript
// 解析存储值（支持 GB/MB/TB 单位）
function parseStorageValue(value: string): number {
  const num = parseFloat(value)
  if (value.includes('TB')) return num * 1024
  if (value.includes('MB')) return num / 1024
  return num // 默认 GB
}

// 计算使用百分比
const usedPercentage = computed(() => {
  const total = parseStorageValue(deviceInfo.value.ios.totalCapacity)
  const available = parseStorageValue(deviceInfo.value.ios.availableCapacity)
  const used = total - available
  return Math.max(0, Math.min(100, (used / total) * 100))
})
```

### 9.2 预加载机制

```typescript
/**
 * 预加载组件 - 在空闲时间按优先级加载
 */
export function preloadComponents(): void {
  const loadByPriority = (priority: 'high' | 'medium' | 'low', delay: number) => {
    setTimeout(() => {
      if ('requestIdleCallback' in window) {
        requestIdleCallback(() => {
          // 按优先级加载组件
        })
      }
    }, delay)
  }
  
  loadByPriority('high', 1000)    // 1秒后加载高优先级
  loadByPriority('medium', 3000) // 3秒后加载中优先级
  loadByPriority('low', 5000)    // 5秒后加载低优先级
}
```

**预加载优先级**:
| 优先级 | 组件 | 加载时机 |
| -------- | ------ | ---------- |
| 高 | EmailApp | 应用启动 1 秒后 |
| 中 | BrowserApp, LiveCenterApp | 应用启动 3 秒后 |
| 低 | ThemeEditor, AboutPhone, GroupMembers 等 | 应用启动 5 秒后 |
