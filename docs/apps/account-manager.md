# 账号管理 App

> **状态**: 已实现
> **路由**: `/account-manager`
> **分类**: 系统 (system)

## 概述

账号管理 App 是一个聚合管理界面，让玩家管理自己在各个平台、各个世界的所有身份。

## 功能

### 1. 玩家身份管理

- 显示玩家的基础身份信息（全局唯一）
- 支持编辑玩家昵称、头像、简介

### 2. 平台账号管理

按平台分组展示所有账号，支持：

- **查看账号列表**：按平台（微博、聊天、B站等）分组展示
- **账号作用域标签**：显示每个账号属于哪个世界（全局/角色卡/会话）
- **创建新账号**：为当前世界或全局创建
- **编辑账号**：修改昵称、用户名、简介
- **删除账号**：清理不需要的身份

### 3. 作用域说明

| 作用域 | 图标 | 说明 |
| ------ | ---- | ---- |
| 全局 | 🌐 | 所有聊天会话共享 |
| 角色卡级 | 🏷️ | 相同角色卡的会话共享 |
| 会话级 | 📍 | 仅当前会话可见 |

## 组件说明

### AccountManagerApp.vue

主入口组件，负责：
- 加载玩家实体和所有平台账号
- 管理弹窗状态（编辑/创建）
- 处理账号的 CRUD 操作

### PlayerIdentityCard.vue

显示玩家的全局身份信息：
- 头像（支持默认首字母）
- 昵称
- 简介
- 作用域标签（始终为全局）

### PlatformAccountGroup.vue

可折叠的平台账号分组：
- 平台图标和名称
- 账号数量统计
- 账号列表（使用 AccountCard）
- 创建新账号按钮

**Props:**

| 属性 | 类型 | 说明 |
| ---- | ---- | ---- |
| `platformId` | `string` | 平台ID |
| `platformName` | `string` | 平台显示名称 |
| `platformIcon` | `string` | 平台图标（FontAwesome 类名） |
| `platformColor` | `string` | 平台主题色 |
| `accounts` | `PlatformAccount[]` | 账号列表 |

### AccountCard.vue

单个账号卡片，显示：
- 头像
- 昵称和用户名（@handle）
- 作用域标签
- 粉丝数（如果有）
- 编辑/删除操作按钮

### AccountEditDialog.vue

编辑账号信息的弹窗：
- 昵称输入
- 用户名（@handle）输入
- 简介输入
- 作用域显示（不可编辑）

### AccountCreateDialog.vue

创建新账号的弹窗：
- 昵称输入（必填）
- 用户名输入（可选）
- 简介输入（可选）
- 作用域选择（全局/角色卡级/会话级）

### 技术要点

1. **获取会话上下文**：
   ```typescript
   // accountStore 自动从 Bridge Adapter 获取真实会话
   const sessionContext = computed(() => accountStore.sessionContext)
   const isConnected = computed(() => sessionContext.value?.sessionId !== 'standalone-session')
   ```

2. **显示会话绑定**：
   ```typescript
   // 在 AccountCard 中显示
   const sessionBindingInfo = computed(() => {
     if (props.account.scope === 'session' && props.account.scopeSessionId) {
       return `会话: ${props.account.scopeSessionId.slice(0, 8)}...`
     }
     return null
   })
   ```

3. **创建账号时自动绑定**：
   - `CreateAccountDialog` 已从 `accountStore.sessionContext` 获取当前会话
   - 选择 `session` 作用域时自动填充 `scopeSessionId`
