### 功能特性

| 功能 | 说明 |
| :----- | :----- |
| 统计入口 | 全部、我的、提示词链、系统提示词四个核心入口 |
| 快捷操作 | 每个操作带有描述说明和跳转箭头 |
| 帮助对话框 | 点击 ℹ️ 按钮可查看提示词/提示词链/系统提示词的详细说明 |
| 搜索 | 全局搜索入口，跳转至 `PromptsList` (scope='search') |
| 导入/导出 | 顶部工具栏支持配置的导入和导出 |
| App 分组 | 自动展示所有注册了提示词的 App |

## 列表页 (PromptsList)

展示特定 Scope 下的提示词，支持分类筛选。

### Scope 机制

| Scope | 说明 |
| :------ | :----- |
| `all` | 显示所有提示词 |
| `user` | 仅显示用户创建的提示词 |
| `builtin` | 仅显示系统内置提示词 |
| `search` | 显示符合搜索关键字的所有提示词 |
| `{appId}` | 显示特定 App 注册的提示词 |

### 分类筛选

根据 `category` 进行二次过滤，内置分类：

| 分类 | 说明 |
| :----- | :----- |
| `all` | 全部分类 |
| `chat` | 聊天对话 |
| `social` | 社交媒体 |
| `email` | 邮件相关 |
| `browser` | 浏览器相关 |
| `live` | 直播相关 |
| `system` | 系统功能 |

### 操作

- 支持 CRUD 操作（复用 `usePromptActions`）
- 仅在 `user` scope 下显示「新建」按钮
- 支持 `?action=add` 参数自动打开新建对话框

## 详情页 (PromptDetail)

查看提示词完整信息，并提供实时渲染测试。

### 三个标签页

#### 1. 基本信息

- 提示词名称、描述、图标
- 场景标识、分类、来源
- 启用状态、优先级、版本
- 创建/更新时间
- 可用变量列表

#### 2. 模板内容

- 系统提示词预览（如有）
- 用户提示词模板预览
- 一键复制功能

#### 3. 测试

- **变量表单**: 根据 `availableVariables` 自动生成
- **渲染预览**: 调用 `PromptService.renderPrompt` 实时预览替换后的文本
- **AI 生成测试**: 调用 `AIGenerateService` 连接真实 AI 进行生成测试
- **取消生成**: 支持中途取消正在进行的生成

### 测试流程

```
1. 填写变量值
       │
       ▼
2. 点击「预览渲染结果」
       │
       ▼
3. 查看替换后的 System/User Prompt
       │
       ▼
4. 点击「执行生成」调用 AI
       │
       ▼
5. 查看 AI 生成结果
```

## 提示词卡片 (PromptCard)

列表页中的提示词展示卡片，支持以下操作：

| 操作 | 图标 | 条件 |
| :----- | :----- | :----- |
| 切换启用 | `toggle-on/off` | 总是可用 |
| 编辑 | `edit` | 有编辑权限时 |
| 复制 | `copy` | 总是可用 |
| 重置 | `undo` | 仅内置提示词 |
| 删除 | `trash` | 有删除权限时 |

### 权限控制

使用 `PromptService.isPromptEditable(prompt)` 检查权限：

| 来源 | 可编辑字段 | 可删除 |
| :----- | :----------- | :------- |
| `user` | 全部 | ✅ |
| `builtin` | `enabled`, `priority` | ❌ |
| `app` | `enabled`, `priority` | ❌ |
