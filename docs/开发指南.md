## 1. 快速开始

### 1.1 环境要求

| 工具 | 版本要求 |
| ------ | ---------- |
| Node.js | >= 18.0.0 |
| npm | >= 9.0.0 |
| VS Code | 推荐最新版 |

### 1.2 推荐 VS Code 扩展

- Vue - Official (Vue 语言支持)
- TypeScript Vue Plugin (Volar)
- Tailwind CSS IntelliSense
- ESLint
- Prettier

### 1.3 克隆并安装

```bash
git clone <repository-url> phone-simulator
cd phone-simulator
npm install
```

### 1.4 启动开发服务器

```bash
npm run dev
```

浏览器访问 `http://localhost:5173`，即可看到独立运行的手机模拟器。

## 4. 添加新功能

### 4.1 添加新 App（推荐方式）

项目使用 Vue Router 管理视图，添加新 App 需要以下步骤：

#### 步骤 1：创建 App 目录结构

```
src/apps/newFeature/
├── index.ts              # 导出入口
└── NewFeatureApp.vue     # 主组件
```

#### 步骤 2：创建主组件

```vue
<!-- src/apps/newFeature/NewFeatureApp.vue -->
<template>
  <div class="new-feature h-full flex flex-col bg-white">
    <div class="app-header flex items-center p-4 border-b">
      <button class="back-btn mr-3" @click="goBack">
        <i class="fas fa-chevron-left"></i>
      </button>
      <span class="title text-lg font-semibold">新功能</span>
    </div>
    
    <div class="content flex-1 overflow-y-auto p-4">
      <!-- 功能内容 -->
    </div>
  </div>
</template>

<script setup lang="ts">
import { useRouter } from 'vue-router'

const router = useRouter()

function goBack() {
  router.back()
}
</script>
```

#### 步骤 3：创建导出入口

```typescript
// src/apps/newFeature/index.ts
export { default as NewFeatureApp } from './NewFeatureApp.vue'
```

#### 步骤 4：注册路由

```typescript
// src/router/index.ts
const routes: RouteRecordRaw[] = [
  // ... 其他路由
  {
    path: '/new-feature',
    name: 'NewFeature',
    component: () => import('@/apps/newFeature/NewFeatureApp.vue'),
    meta: { transition: 'slide-left' }
  },
]
```

#### 步骤 5：在主屏幕添加入口

```typescript
// src/apps/home/HomeScreen.vue
const apps: AppItem[] = [
  // ... 其他应用
  {
    id: 'newFeature',
    name: '新功能',
    icon: 'fas fa-star',
    iconBg: 'bg-purple-500',
    route: '/new-feature'  // 对应路由路径
  },
]

function openApp(app: AppItem) {
  router.push(app.route)
}
```

### 4.2 添加带子路由的 App

对于有详情页的 App，使用嵌套路由：

```typescript
// src/router/index.ts
{
  path: '/new-feature',
  name: 'NewFeature',
  component: () => import('@/apps/newFeature/NewFeatureApp.vue'),
  children: [
    {
      path: ':itemId',
      name: 'NewFeatureDetail',
      component: () => import('@/apps/newFeature/NewFeatureDetail.vue'),
      props: true  // 将路由参数作为 props 传递
    }
  ]
}
```

在组件中使用路由参数：

```vue
<!-- src/apps/newFeature/NewFeatureDetail.vue -->
<script setup lang="ts">
defineProps<{
  itemId: string  // 从路由参数自动注入
}>()
</script>
```

### 4.3 添加新 Store

```typescript
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

export const useNewFeatureStore = defineStore('newFeature', () => {
  const items = ref<Item[]>([]);
  
  const itemCount = computed(() => items.value.length);
  
  function addItem(item: Item) {
    items.value.push(item);
  }
  
  function removeItem(id: string) {
    const index = items.value.findIndex(i => i.id === id);
    if (index !== -1) {
      items.value.splice(index, 1);
    }
  }
  
  function $reset() {
    items.value = [];
  }
  
  return {
    items,
    itemCount,
    addItem,
    removeItem,
    $reset,
  };
}, {
  persist: {
    key: 'phone-simulator-new-feature',
    paths: ['items'],
  },
});
```

## 6. 测试

### 6.1 运行测试

```bash
npm run test
npm run test:coverage
```

### 6.2 编写单元测试

```typescript
import { describe, it, expect, beforeEach } from 'vitest';
import { setActivePinia, createPinia } from 'pinia';
import { useChatStore } from '@/stores/chatStore';

describe('ChatStore', () => {
  beforeEach(() => {
    setActivePinia(createPinia());
  });
  
  it('should add message', () => {
    const store = useChatStore();
    
    store.addMessage('contact_001', {
      id: 'msg_001',
      type: 'text',
      content: 'Hello',
      senderId: 'contact_001',
      timestamp: Date.now(),
      isSent: false,
      status: 'delivered',
    });
    
    const messages = store.getMessages('contact_001');
    expect(messages).toHaveLength(1);
    expect(messages[0].content).toBe('Hello');
  });
  
  it('should mark as read', () => {
    const store = useChatStore();
    store.markAsRead('contact_001');
    
    const conv = store.conversations['contact_001'];
    expect(conv.unreadCount).toBe(0);
  });
});
```

## 8. 常见问题

### 8.1 图标不显示

确保 `index.html` 中包含 Font Awesome CDN：

```html
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css" />
```

### 8.2 样式不生效

1. 检查 TailwindCSS 是否正确配置
2. 确认 `src/assets/styles/index.css` 被导入
3. 清除浏览器缓存

### 8.3 状态不持久化

1. 检查 Store 的 persist 配置
2. 确认 localStorage 未被禁用
3. 检查控制台是否有序列化错误

### 8.4 Mock 服务不工作

1. 确认在开发模式下运行（`npm run dev`）
2. 检查 `import.meta.env.DEV` 值
3. 查看控制台是否有 Mock 初始化日志

### 8.5 TypeScript 类型错误

1. 运行 `npm run type-check`
2. 确认类型定义文件正确导入
3. 检查 `tsconfig.json` 的 paths 配置

## 9. 贡献指南

### 9.1 分支策略

- `main` - 主分支，保持稳定
- `develop` - 开发分支
- `feature/*` - 功能分支
- `fix/*` - 修复分支

### 9.2 提交规范

使用 Conventional Commits：

```
feat: 添加朋友圈点赞功能
fix: 修复消息发送失败的问题
docs: 更新 API 文档
style: 调整按钮样式
refactor: 重构消息解析器
test: 添加 ChatStore 测试
chore: 更新依赖版本
```

### 9.3 PR 流程

1. Fork 项目
2. 创建功能分支
3. 编写代码和测试
4. 提交 PR 到 develop 分支
5. 等待 Code Review
6. 合并到主分支
