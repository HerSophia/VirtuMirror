## 核心组件

| 组件                      | 职责                         | 通用/扩展 |
| ------------------------- | ---------------------------- | --------- |
| `LLMTaskService`          | 服务入口，协调各组件         | 通用      |
| `TaskRegistry`            | 管理任务定义（来自各 App）   | 通用      |
| `TaskExecutor`            | 执行任务、变量替换、LLM 调用 | 通用      |
| `TaskScheduler`           | 自动执行调度、定时器管理     | 通用      |
| `ContextProviderRegistry` | 管理上下文提供器             | 通用      |
| `OutputHandlerRegistry`   | 管理输出处理器               | 通用      |
| `WeiboPlugin`             | 微博专用任务、处理器、提供器 | 扩展      |

## 目录结构

### 系统服务

```text
src/services/llmTask/
├── index.ts                        # 统一导出
├── types.ts                        # 类型定义
├── LLMTaskService.ts               # 服务主类（单例）
├── TaskRegistry.ts                 # 任务定义注册表
├── TaskExecutor.ts                 # 任务执行器
├── TaskScheduler.ts                # 自动执行调度器
├── VariableResolver.ts             # 变量替换引擎
├── ContextProviderRegistry.ts      # 上下文提供器注册表
├── OutputHandlerRegistry.ts        # 输出处理器注册表
├── builtinProviders.ts             # 内置上下文提供器（时间等）
└── utils.ts                        # 工具函数
```

### 系统 Store

```text
src/stores/
└── llmTaskStore.ts                 # 系统级响应式状态
```

### App 扩展（以微博为例）

```text
src/apps/weibo/
├── llmTask/                        # LLM 任务扩展
│   ├── index.ts                    # 注册入口
│   ├── weiboTaskDefinitions.ts     # 任务定义
│   ├── weiboContextProviders.ts    # 上下文提供器
│   ├── weiboOutputHandlers.ts      # 输出处理器
│   └── parsers/                    # 解析器
│       ├── dispatcher.ts
│       ├── postParser.ts
│       ├── commentParser.ts
│       └── ...
└── manifest.ts                     # 应用清单（调用注册）
```

## 数据流

### 任务执行流程

```text
用户点击执行
      │
      ▼
┌─────────────────┐
│ LLMTaskService  │
│ executeTask()   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ TaskExecutor    │
│ 1. 获取任务定义  │
│ 2. 收集上下文    │
│ 3. 变量替换      │
│ 4. 调用 LLM     │
│ 5. 调用处理器   │
└────────┬────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
┌────────┐ ┌────────┐
│Context │ │Output  │
│Provider│ │Handler │
└────────┘ └────────┘
```

### 自动执行流程

```text
启动自动执行
      │
      ▼
┌─────────────────┐
│ TaskScheduler   │
│ 1. 计算下次时间  │
│ 2. 设置定时器    │
└────────┬────────┘
         │
    定时器触发
         │
         ▼
┌─────────────────┐
│ TaskExecutor    │
│ executeTask()   │
└────────┬────────┘
         │
    执行完成
         │
         ▼
┌─────────────────┐
│ TaskScheduler   │
│ 调度下次执行     │
└─────────────────┘
```
